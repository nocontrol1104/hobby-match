プライバシーポリシー・免責事項

シュミのたね運営事務局（以下「運営者」）は、趣味診断サイト「シュミのたね」（以下「本サイト」）での利用者の情報の扱いを、以下のとおり定めます。

1. 診断の回答について

  • 診断の回答と結果は、お使いのブラウザの中（localStorage）と、結果ページの URL にだけ保存されます。運営者のサーバーには送られません。
  • ブラウザには、前回の結果を表示するために、回答と、個人を特定しないランダムな ID を保存します。ブラウザのサイトデータを消すと削除されます。
  • 結果ページの URL には回答が含まれます。URL を共有すると、受け取った人も同じ結果を見られます。

2. アクセス解析ツールについて

本サイトでは、サイトの改善のために Google LLC のアクセス解析ツール「Google アナリティクス」を利用することがあります。Google アナリティクスは Cookie を使って、訪問したページ、診断を始めた・終えた回数、診断のタイプ、リンクのクリックやシェアなどの利用状況を集めます。このデータは匿名で集められ、個人を特定するものではありません。

データの扱いは Google のポリシーと規約 をご覧ください。収集を止めたい場合は、Google アナリティクス オプトアウト アドオン を使うか、ブラウザで Cookie を無効にしてください。

3. 広告（アフィリエイト）について

  • 本サイトは、アフィリエイトプログラム（成果報酬型の広告）に参加しています。紹介する商品やサービスのリンクから申し込みや購入があると、運営者が紹介料を受け取ることがあります。広告のリンクの近くには「PR」と表示します。
  • 広告を配信する事業者（ASP）は、成果を確認するために Cookie を使うことがあります。
  • 診断のおすすめの順位は、診断の計算だけで決めています。紹介料の高さでは変えていません。
  • 商品やサービスの購入・利用は、リンク先の事業者と利用者の間の取引です。内容や条件はリンク先でご確認ください。

4. 外部サービスについて

  • 本サイトは GitHub Pages（GitHub, Inc.）で公開しています。GitHub はサービスの運用のため、アクセスした人の IP アドレスなどを記録することがあります。
  • 文字の表示に Google Fonts を使っています。ページを開くと、フォントを読み込むために Google のサーバーに接続します。
  • X（旧 Twitter）・LINE のシェアボタンは、押したときだけ各サービスに移動するリンクです。
  • 事前登録とお問い合わせには Google フォームを使います。入力した内容は、その目的（お知らせの送信、お問い合わせへの返信）にだけ使います。

5. 個人情報の第三者への提供

運営者は、法令に基づく場合を除き、利用者の同意なく個人情報を第三者に提供しません。

6. 免責事項

  • 診断の結果は、趣味を見つけるきっかけとしての目安です。結果の正確さや、趣味が必ず合うことを保証するものではありません。
  • 費用や時間の目安は、作成時点の一般的な情報をもとにしています。実際の費用や条件は、リンク先や各サービスでご確認ください。
  • 本サイトの情報や、リンク先のサイトを利用して生じた損害について、運営者は責任を負いかねます。

7. 改定

このポリシーは、必要に応じて予告なく改定することがあります。改定後の内容は、このページに掲載した時点から効力を持ちます。
